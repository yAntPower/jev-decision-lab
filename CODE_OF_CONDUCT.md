# Code of Conduct

Jev Decision Lab welcomes people with different backgrounds and experience levels. Be respectful and constructive in issues, pull requests, reviews, and other project spaces. Critique ideas and code without personal attacks. Harassment, threats, discriminatory language, and publishing another person's private information are not acceptable.

Maintainers may edit, hide, or remove contributions that violate these expectations and may restrict participation when needed. For a conduct concern that can be described publicly, open an issue and mark it as a conduct concern. If public disclosure would expose private information, use GitHub's private reporting options and do not include sensitive details in a public issue. Security vulnerabilities follow [SECURITY.md](SECURITY.md).

## 中文

欢迎不同背景和经验的贡献者。在 Issue、Pull Request 和代码评审中请尊重他人、聚焦问题与代码。禁止骚扰、威胁、歧视性语言和公开他人隐私。维护者可以编辑、隐藏或移除违反规则的内容，并在必要时限制参与。可以公开描述的问题请提交 Issue；涉及隐私或安全信息时，请使用 GitHub 的私密报告渠道，不要在公开 Issue 中披露敏感内容。安全漏洞请参阅 [SECURITY.md](SECURITY.md)。
